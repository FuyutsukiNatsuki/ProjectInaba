# 🌕 Project Inaba

デスクトップに常駐する、あなただけの賢くて可愛いローカルAIマスコット「因幡ムツキ」のシステムプロジェクトです。
Unityによる透過ウィンドウUIと、PythonによるローカルLLMサーバーを連携させた実験的アプリケーションです。

## ✨ 主な機能 (Features)

* **シームレスなデスクトップ常駐 (Transparent Window)**: Win32 APIを活用し、背景を完全に透過。キャラクターをデスクトップの最前面に表示しつつ、裏側のウィンドウ操作も妨げない独自のクリック貫通・検知システムを搭載しています。
* **ローカルLLMによる高度な対話 (Local LLM Integration)**: Ollama (Gemma 4B / Qwen 等) をバックエンドに使用し、完全ローカル環境でセキュアかつ感情豊かなロールプレイ会話を実現します。CPU推論でも動作するよう設計されています。
* **長期記憶システム (Memory System)**: ChromaDBによるベクトル検索を用いた記憶システムを搭載。過去の対話内容を文脈として踏まえた、連続性のある会話が可能です。
* **音声合成出力 (Text-to-Speech)**: Piperを利用し、ローカル環境下での高速な音声出力を実装しています。
* **パーソナライズ＆UIカスタマイズ (Customizable UI)**: ユーザー名の記憶機能に加え、10種類のテーマカラーからお好みのUIデザインを選択・保存可能です。
* **会話ログ機能 (Chat Log)**: 過去の対話履歴をスクロールビューで後から振り返ることができます。

## 🛠️ 技術スタック (Tech Stack)

* **Frontend**: Unity (C#), Windows API (user32.dll / Dwmapi.dll)
* **Backend**: Python, FastAPI
* **AI / ML**: Ollama (Gemma / Qwen), Piper (TTS), ChromaDB

## 🚀 使い方 (Getting Started)

1. 本リポジトリをクローンします。
2. `Python` 側のサーバー環境を構築し、必要なライブラリをインストールして起動します。
   * **※注意:** LLMモデル（Ollama）やPiperのモデルデータ本体は本リポジトリに含まれていません。各自でご用意の上、Python側の設定ファイルにて相対パス等を適宜書き換えてください。
3. `Unity` プロジェクトを開き、ビルドして実行します。フルスクリーン・ウィンドウモードを併用し、デスクトップ上にシームレスに配置されます。
